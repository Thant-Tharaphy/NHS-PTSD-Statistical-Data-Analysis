Why left and many_to_one?

  • how="left" → keeps all rows from the main dataset (ethnicity_long) and adds matching base information.

  • If no match is found, the row stays but the base becomes NaN.

  • validate="many_to_one" → checks that many percentage rows match one base row.

Example:

Many:

  • Men + Asian + Trauma
  • Men + Asian + PTSD
  • Men + Asian + Observed/Standardised

→ One:

  • Men + Asian base
