# NHS-PTSD-Statistical-Data-Analysis
Python-based exploratory data analysis and statistical investigation of PTSD patterns using NHS Adult Psychiatric Morbidity Survey data.
# NHS PTSD Statistical Analysis

## Project Overview

This project explores post-traumatic stress disorder (PTSD) screening outcomes using data from the NHS Adult Psychiatric Morbidity Survey (APMS).

The analysis investigates patterns across demographic, socioeconomic, geographical and health-related characteristics.

## Objectives

- Understand and prepare NHS survey tables for analysis.
- Clean and restructure data using Python and Pandas.
- Conduct exploratory data analysis (EDA).
- Visualise PTSD-related patterns across population groups.
- Apply appropriate statistical methods to investigate relationships and differences.
- Interpret findings while considering sample sizes and survey limitations.

## Tools and Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook
- Excel
- Statistical analysis

## Project Structure

Individual Jupyter notebooks document the data preparation and analysis of each NHS table.

## Project Status

This is an ongoing project. Notebooks and analytical findings will be added progressively as each stage is completed.

## Data Source

NHS Adult Psychiatric Morbidity Survey (APMS). Relevant source references and survey documentation will be included alongside the analysis.
