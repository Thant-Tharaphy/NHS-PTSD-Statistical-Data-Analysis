Table 3.11 — Understanding the Table¶

Purpose:
Compare current medication use between adults who screen positive and negative for probable PTSD.

Population:
All adults.

Main groups:

  • PTSD screen positive
  • PTSD screen negative

What is measured:
Percentage currently taking different types of medication, such as:

  • Sleep medication
  • Anxiety medication
  • Depression medication
  • ADHD medication
  • Psychosis medication
  • Bipolar disorder medication
  • Any psychotropic medication
  • Substance dependence medication

Bases:

  • Unweighted base = actual sample size
  • Weighted base = survey-adjusted base

Main analysis:
Compare medication percentages between PTSD screen-positive and screen-negative adults and calculate the percentage-point difference.

Important:
The results show an association, not causation.

    style="whitegrid",

Table 3.11 — Key Findings¶

Medication use was higher among adults who screened positive for probable PTSD than among adults who screened negative across all medication categories shown.

The largest differences were:

  • Any psychotropic medication: about 35.23 percentage points
  • Depression: about 33.35 percentage points
  • Anxiety: about 29.52 percentage points

For any psychotropic medication:

  • Screen positive: 45.63%
  • Screen negative: 10.40%

Overall, the results show a clear descriptive association between PTSD screening status and medication use.

These results describe differences between the groups and do not show causation or statistical significance.
